# FitCampus — SIH26196

FitCampus is a fitness and wellness dashboard prototype built for Smart India Hackathon project **SIH26196**.

## GitHub root directory

```text
FitCampus-SIH26196/
├── public/
│   └── index.html
├── .env.example
├── .gitignore
├── package.json
├── package-lock.json        # generated by npm install
├── README.md
└── server.js
```

## Tech stack

- HTML, CSS and JavaScript (frontend)
- Node.js and Express (backend)
- Anthropic API (AI coach and task suggestions)

## Run locally

1. Install Node.js 20 or newer.
2. Open a terminal in this project folder.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Copy `.env.example` to `.env`.
5. Put your own Anthropic API key in `.env`:

   ```env
   ANTHROPIC_API_KEY=your_real_key_here
   ANTHROPIC_MODEL=claude-sonnet-4-6
   PORT=3000
   ```

6. Start the app:

   ```bash
   npm start
   ```

7. Open `http://localhost:3000`.

Do not open `public/index.html` directly as a file; use the local server so the `/api/...` endpoints work.

## API-key protection

- The browser now sends AI requests to `/api/coach` and `/api/task-suggestion`.
- Only `server.js` reads `ANTHROPIC_API_KEY` from the server environment.
- The real `.env` file is ignored by Git.
- `.env.example` contains only a placeholder and is safe to commit.
- The server applies security headers, JSON size limits and rate limiting to API requests.

**Never paste a real API key into `public/index.html`, commit it to GitHub, or share it in screenshots.** If a real key was previously placed in code or uploaded, revoke it with the provider and create a new one.

## Important prototype limitations

The current app stores its demo profile and password in the browser's `localStorage`. This is **not secure account authentication** and should not be used for real accounts or sensitive personal information. Before production deployment, implement server-side authentication, password hashing, database storage, HTTPS, and appropriate privacy/security controls.

The app also uses external avatar and QR-code image services. Avoid entering sensitive personal information into those services.
